# OPMC-Align: Optimal Partial Transport-Based Fine-Grained Alignment under Incomplete Local Correspondences for Text-to-Image Person Re-Identification

Official PyTorch implementation of the paper **Optimal Partial Transport-Based Fine-Grained Alignment under Incomplete Local Correspondences for Text-to-Image Person Re-Identification**.

OPMC-Align addresses incomplete local correspondences in text-to-image person re-identification and introduces two modules: **OPTFA** (Optimal Partial Transport-Based Fine-Grained Alignment), which models many-to-many relations between image patches and text tokens through optimal partial transport and introduces dustbin nodes to handle unmatched local contents; and **LMC** (Local Matching Calibration), which utilizes the local matching states generated by OPTFA to calibrate the weighted bidirectional cross-modal Circle loss. During inference, only global image-text features are used for retrieval.

## Usage


### Requirements

We use a single NVIDIA RTX 5090 GPU for training and evaluation.


### Prepare Datasets

Download the CUHK-PEDES dataset from [here](https://github.com/ShuangLI59/Person-Search-with-Natural-Language-Description), ICFG-PEDES dataset from [here](https://github.com/zifyloo/SSAN) and RSTPReid dataset from [here](https://github.com/NjtechCVLab/RSTPReid-Dataset).

Organize them in `your dataset root dir` folder as follows:

```
|-- your dataset root dir/
|   |-- <CUHK-PEDES>/
|       |-- imgs
|            |-- cam_a
|            |-- cam_b
|            |-- ...
|       |-- reid_raw.json
|
|   |-- <ICFG-PEDES>/
|       |-- imgs
|            |-- test
|            |-- train
|       |-- ICFG_PEDES.json
|
|   |-- <RSTPReid>/
|       |-- imgs
|       |-- data_captions.json
```


### Prepare Pre-train Model Checkpoint

The CLIP ViT-B/16 checkpoint is required for training. Please prepare the corresponding pre-trained model checkpoint before training.


## Training

To train OPMC-Align, you can run the following command:

```
bash run_opmc.sh
```

or modify the dataset and paths in `run_opmc.sh`:

```
DATASET_NAME="CUHK-PEDES"

CUDA_VISIBLE_DEVICES=0 \
python train.py \
--name opmc_align \
--img_aug \
--batch_size 64 \
--MLM \
--dataset_name ${DATASET_NAME} \
--loss_names 'sdm+id+mlm+wbcmcir' \
--root_dir 'path to your data' \
--wbcmcir_loss_weight 0.05 \
--wbcmcir_warmup_epochs 5 \
--circle_delta_p 0.63 \
--circle_delta_n 0.24 \
--circle_m 0.15 \
--lmc_eta 2.0 \
--lmc_norm minmax \
--optfa_iters 20 \
--optfa_lambda 0.1 \
--optfa_rho 0.5 \
--optfa_split 4 \
--optfa_dust_mode global \
--num_epoch 60
```
